# Dirichlet L evaluation at one

The packaged fragment shader uses the character combination in
[DLMF 25.15.3](https://dlmf.nist.gov/25.15.E3) and the Hurwitz
Euler–Maclaurin expansion in [DLMF 25.11.7](https://dlmf.nist.gov/25.11.E7).
Each character sums to zero. Replace each Hurwitz pole term with
`(exp(-delta * log(tail)) - 1) / delta`. The subtracted constants sum to
zero before any division. At `delta = 0`, the term is `-log(tail)`.

## Approximation budget

For `z = -delta * log(tail)` with `|z| <= 1/8`, the shader uses the first
six coefficients of `expm1(z)/z`. The absolute remainder is at most
`exp(|z|) * |z|^6 / 7!`, multiplied by `log(tail)` for each regularized
tail. In the near-one test square `|Re(s)-1| <= 0.01`, `|Im(s)| <= 0.01`
we have `|z| < 0.028`. After combining at most four terms and applying
`q^(-Re(s))`, the series contributes less than `1.6e-13`.

For `sigma = Re(s)`, let `(s)_6 = s(s+1)...(s+5)`. The
Euler–Maclaurin remainder after the B6 term is bounded in absolute
value by

```text
|(s)_6| * sup|periodic B6| / 6! * tail^(-sigma-5) / (sigma+5).
```

[The Fourier series for B6](https://dlmf.nist.gov/24.8.E1) bounds
`sup|periodic B6|` by `1/42`. With `sigma >= 0.99`, `|s| < 1.011`
and `tail >= 6 + 1/q`, the absolute bound on the combined L remainder
is below `6e-8` for all three conductors. This bound excludes binary32
rounding. Each tested shader value must satisfy
`abs(actual-reference) <= 2e-5 + 2e-5 * abs(reference)`. The same
threshold is checked at selected viewport and series-transition points.

## Reference values

The fixture contains 53 points per character in the near-one square, plus
five points in the default viewport and four around the series transition.
Coordinates are rounded to binary32 before evaluating each reference.
Columns carry 46 displayed digits. Generation used mpmath 1.3.0 at 76
decimal digits and two independent formulations.

The primary computation integrates
`t^(s-1) * F_q(exp(-t)) / Gamma(s)` from zero to infinity with split points
at 1 and 8. Here `F_q(u)` is the sum of the period polynomial over a
geometric series. From [DLMF 25.15.1](https://dlmf.nist.gov/25.15.E1),
the three simplified factors are

```text
F_3(u) = u / (1 + u + u^2)
F_4(u) = u / (1 + u^2)
F_5(u) = u(1-u^2) / (1 + u + u^2 + u^3 + u^4)
```

Integrating by parts for the extra points gives
`t^s * u * F_q'(u) / Gamma(s+1)` with `u = exp(-t)). This converges
for `Re(s) > -1`. The integrals agree with mpmath's `dirichlet` Hurwitz
route away from one to within `1.1e-61` overall.

At one the integral reduces to integrating `F_q(u)/u` from 0 to 1.
The first two rational integrals give `pi/(3 sqrt(3))` and `pi/4`.
For `phi = (1+sqrt(5))/2`, the third integrand is `1/sqrt(5)` times the
logarithmic derivative of
`(u^2 + phi*u + 1) / (u^2 + (1-phi)*u + 1)`. Its integral is
`2 log(phi) / sqrt(5)`. The three fixture values at one were checked
against those identities.

## Running the check

Use Ithon at `9d530f4ad51f5b0a09c3e74dbe45cac5bb6d52d3` with the Linux
Mesa EGL loader. Run the absolute paths to its `ithon` entry point and this
directory's `check.pi` with `EGL_PLATFORM=surfaceless` and
`LIBGL_ALWAYS_SOFTWARE=1`. The workflow pins Ithon and checks out the
pull-request head directly.

The probe compiles and links the entire packaged fragment, then submits
one input at a time to its evaluator and reads a binary32 framebuffer
attachment. Only the fragment entry point is replaced in the probe. A
separate draw uses the unmodified application entry point. The negative
controls change a character sign, change a conductor factor, restore
singular division, and restore the symmetric sampling. The last control
is rejected by the direct-coordinate dispatch check.

The generated-tail job independently compiles its checked Idriç source,
validates and links its output, and uses the same GLES readback path to
check five values of the generated fragment. The points include zero, a
conjugate pair, and inputs near the local series limit. These reference
values use mpmath's complex `expm1` at 65 decimal digits, and a test
passes when the absolute complex error is at most `2e-6`.

See the [checked source record](../../examples/autogenerated/regular-hurwitz-tail/attempt.md)
for the scope of the generated fragment and the Android workflow for emulator
coverage. Physical acceptance remains on the SVITOO TAB_P10.
